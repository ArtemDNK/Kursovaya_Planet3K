# Расчет планетарной передачи 3K

Программа на Delphi (VCL) для проектного и проверочного расчета
планетарной зубчатой передачи по схеме **3K** (схема Джеймса с двухвенцовым
сателлитом). По мощности, частоте вращения и требуемому передаточному отношению
программа подбирает числа зубьев, модуль и ширину венцов, проверяет все
зацепления на контактную и изгибную прочность по ГОСТ 21354-87 и выводит
несколько вариантов передачи для разных термообработок и коэффициентов ширины
венца.

## Схема передачи

```
  вход ──► a ──(внешнее)── g ═══ f ──(внутреннее)── e ──► выход
                           │
                      (внутреннее)
                           │
                           b  (неподвижно)

  g ═══ f — два венца одного сателлита, сидят на водиле h
```

- Вход — солнечная шестерня **a**, выход — колесо **e**, колесо **b**
  неподвижно.
- Сателлит состоит из двух жестко связанных венцов: **g** зацепляется с a и b,
  **f** — с e.
- Передаточное отношение:

  U = (1 + zb/za) / (1 − zb·zf / (zg·ze))

Схема 3K дает большие передаточные отношения в одной ступени. Реально
подбираемый диапазон — примерно **U = 10…500**.

## Сборка и запуск

1. Откройте `Project2.dproj` в Delphi (XE2 или новее, VCL, Windows).
2. Соберите и запустите проект (F9).

Проект состоит из модулей:

| Файл | Назначение |
|---|---|
| `Project2.dpr` | главная программа |
| `Unit1.pas/.dfm` | главная форма: ввод исходных данных, вывод вариантов |
| `Unit4.pas/.dfm` | окно ввода передаточного отношения и допуска на него |
| `Unit5.pas/.dfm` | окно выбора схемы расположения колес относительно опор |
| `CALCULAT008.pas` | весь расчет передачи (без зависимостей от VCL) |
| `Materials.pas` | таблица механических характеристик сталей |
| `constants.pas` | списки для полей формы и допустимые диапазоны исходных данных |

Файлы `CALCULAT.PAS`, `CogWheelTransmission.PAS` (исходная DOS-версия расчета
цилиндрической передачи) и `Unit2.pas` (окно выбора типа зубьев) в сборку не
входят. Они оставлены как справочный материал.

Исходники в кодировке Windows-1251.

## Как пользоваться

1. Заполните исходные данные на главной форме:
   - **Мощность на ведущем валу**, кВт (0.1…200);
   - **Частота вращения шестерни** a, об/мин (10…10000);
   - **Передаточное отношение**: щелчок по полю открывает окно, где задаются U
     и допуск на него в процентах (2…10 %);
   - **Расчетный срок службы**, ч;
   - **Число сателлитов** (1…6);
   - **Коэффициент внешней динамики** K_A (1.0 — равномерная нагрузка);
   - **Режим нагружения**: типовой режим ГОСТ 21354 (постоянный, тяжелый,
     средний равновероятный, средний нормальный, легкий, особо легкий). Если
     снять галочку «Типовой», нагрузка считается по циклограмме;
   - **Быстроходность** и **схема расположения колес** — влияют на выбор
     коэффициента ширины венца ψba и на коэффициент K_Hβ;
   - **Реверс** — передача работает в обе стороны.
2. Для каждого колеса задайте материал, термообработку, деформационное
   упрочнение, шероховатость, способ получения заготовки, обработку выкружки и
   зуборезный инструмент:
   - «шестерня» — солнечная шестерня a;
   - «сателлит» — оба венца сателлита, g и f;
   - «колесо» — неподвижное колесо b;
   - «второе колесо» — выходное колесо e.

   Термообработка `AUTO` перебирает все термообработки выбранной стали, которые
   есть в таблице материалов. Каждая комбинация дает отдельные варианты.
3. Нажмите **«Посчитать»**. Каждый найденный вариант открывается на отдельной
   вкладке. Если вариантов нет, программа сообщает причину.

### Что выводится

- исходные данные варианта (материалы, термообработки);
- фактическое передаточное отношение и отклонение от заданного, КПД, частоты
  вращения выходного колеса и водила, моменты на валах;
- модуль, межосевое расстояние, ψba, степень точности;
- для каждого из пяти венцов: число зубьев z, диаметры d, da, df, ширина b;
- для каждого зацепления (a-g, g-b, f-e): контактное напряжение и допускаемое,
  то же при пиковой нагрузке, силы Ft, Fr, Fx на один сателлит, скорость,
  коэффициент перекрытия;
- для каждого венца — напряжения изгиба и допускаемые (номинальные и пиковые);
- масса зубчатых колес и габаритный объем.

## Методика расчета

### 1. Подбор чисел зубьев

- za выбирается по твердости шестерни: 24 при HB ≤ 350, 21 при HRC ≤ 52,
  18 при большей твердости. Если для этого za сочетания нет, пробуются соседние
  значения.
- Перебираются zg и zf (не меньше 17 — нет подрезания) при условиях:
  - **соосность** (все колеса без смещения, модуль одинаковый):
    zb = za + 2·zg, ze = zf + za + zg;
  - **точность** передаточного отношения: |U_ф − U| ≤ ΔU·U;
  - **сборка**: (za + zb) кратно nw и (za·zf + ze·zg) кратно nw·НОД(zf, zg);
  - **соседство**: (za + zg)·sin(π/nw) > max(zg, zf) + 2.5.
- Из подходящих сочетаний берется самое компактное (наименьшее из zb, ze).

### 2. Кинематика и КПД

- Частота вращения водила: n_h = n1 / (1 + zb/za).
- Частота вращения выходного колеса: n2 = n1 / U_ф.
- Числа циклов нагружения считаются по частотам вращения колес относительно
  водила с учетом числа сателлитов.
- КПД оценивается по потерям мощности в относительном движении (метод
  Крейнеса). Для каждого зацепления коэффициент потерь
  ψ = 2.3·f·(1/z1 ± 1/z2), где f = 0.08. Потери в подшипниках учтены
  множителем 0.99.
- Моменты: T1 = 9549·P1/n1, T2 = T1·U_ф·η, реактивный момент на колесе b:
  Tb = T2 − T1.

### 3. Проектный расчет

Для каждого зацепления межосевое расстояние находится из условия контактной
прочности:

aw = Ka·(u ± 1)·∛(K_Hβ·T_ш / (ψba·u·σHP²)),

где Ka = 495 для прямых зубьев и 430 для косых, T_ш — момент на шестерне пары
на один сателлит. Берется наибольшее из трех значений и пересчитывается в
модуль: m = 2·aw·cos β / (za + zg).

### 4. Проверочный расчет (ГОСТ 21354-87)

Модуль увеличивается по стандартному ряду, пока для всех зацеплений и колес не
выполнится:

- **Контактная прочность:**
  σH = Z_E·Z_H·Z_ε·√(Ft·K_H·(u ± 1) / (bw·d1·u)) ≤ 1.05·σHP;
  K_H = K_A·K_Hv·K_Hβ·K_Hα. Знак «+» — внешнее зацепление, «−» — внутреннее.
- **Контактная прочность при пиковой нагрузке:** σH·√K_пер ≤ σHPmax.
- **Изгибная прочность:**
  σF = Ft·K_F·Y_FS·Y_β·Y_ε / (bw·m) ≤ σFP; K_F = K_A·K_Fv·K_Fβ·K_Fα.
- **Изгиб при пиковой нагрузке:** σF·K_пер ≤ σFPmax.

Нагрузка Ft умножается на коэффициент неравномерности распределения нагрузки
между сателлитами K_w: 1.0 при одном сателлите, 1.1 при двух, 1.15 при трех,
1.2 при большем числе.

Допускаемые напряжения:

- σHP = σHlim·Z_N·Z_R·Z_v·Z_X / S_H, где σHlim:

  | Термообработка | σHlim |
  |---|---|
  | улучшение, нормализация, отжиг | 2·HB + 70 |
  | объемная закалка | 18·HRC + 150 |
  | закалка ТВЧ | 17·HRC + 200 |
  | цементация, нитроцементация | 23·HRC |
  | азотирование | 1050 |

- σFP = σFlim0·Y_Z·Y_g·Y_d·Y_A·Y_N·Y_δ·Y_R·Y_X / S_F. Венец g сателлита
  нагружается с двух сторон (от a и от b), поэтому для него всегда учитывается
  коэффициент реверса Y_A.
- σHPmax и σFPmax — по ГОСТ, в зависимости от термообработки и заготовки.

Для пары колес допускаемое контактное напряжение равно меньшему из двух. Для
косозубых колес — 0.45·(σHP1 + σHP2), но не больше 1.23·σHPmin.

### 5. Размеры, силы, масса

- Колеса без смещения: d = m·z / cos β.
- Внешние зубья: da = d + 2m, df = d − 2.5m.
- Внутренние зубья: da = d − 2m, df = d + 2.5m.
- Силы на один сателлит: Ft, Fr = Ft·tg αt, Fx = Ft·tg β.
- Масса — по объему венцов (сталь, 7.85 г/см³), обод внутренних колес
  принят толщиной 3m.

## Сообщения об ошибках

| Сообщение | Что делать |
|---|---|
| нет сочетания чисел зубьев… | изменить U (схема 3K не реализует U < ~10), допуск или число сателлитов |
| для выбранной стали нет данных по выбранной термообработке | выбрать другую термообработку или `AUTO` |
| прочность не обеспечивается даже при модуле 25 мм | уменьшить нагрузку, выбрать более прочный материал или увеличить число сателлитов |
| слишком низкий КПД | уменьшить U: возможно самоторможение |

## Допущения и ограничения

- Все колеса нарезаются без смещения исходного контура. Модуль во всех
  зацеплениях одинаковый.
- Галочка «Стандартное межосевое расстояние» не используется: у соосной
  планетарной передачи межосевое определяется модулем и числами зубьев.
- Тип зубьев на форме не выбирается (окно `Unit2` не подключено), поэтому
  расчет ведется для прямых зубьев. Модуль расчета поддерживает косые и
  шевронные зубья (`Tipz` = 2, 3).
- Зуборезный инструмент выводится в результатах, но в расчете не учитывается.
- Коэффициент формы зуба внутренних колес Y_FS берется по формуле для внешних
  колес с x = 0. Это дает небольшой запас.
- Значения K_w, коэффициент трения для КПД и рекомендуемые ψba — типовые
  справочные значения. При необходимости их можно изменить в начале
  `CALCULAT008.pas`.
